# Modelový byt A — Lidická 1903/96, Břeclav

Virtuální prohlídka a video průchod modelovým bytem A. Rendery Blender Cycles.

- **Prohlídka:** [thebehunek.github.io/byt-a-lidicka](https://thebehunek.github.io/byt-a-lidicka/) — šest panoramat 4096 × 2048, průchod šipkami. Odkaz na konkrétní místo přidáním uzlu, např. `#P2` (ložnice).
- **Video:** [video/byt-a-prochazka.mp4](video/byt-a-prochazka.mp4) — 1 732 snímků, 1920 × 1080, 25 fps, 69 s.

Zdrojová scéna a výkresy nejsou součástí tohohle repozitáře.
