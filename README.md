# Modelový byt A — Lidická 1903/96, Břeclav

Virtuální prohlídka a video průchod modelovým bytem A. Rendery Blender Cycles.

- **Prohlídka:** [thebehunek.github.io/byt-a-lidicka](https://thebehunek.github.io/byt-a-lidicka/) — šest panoramat 4096 × 2048, průchod šipkami. Odkaz na konkrétní místo přidáním uzlu, např. `#P2` (kuchyň) nebo `#P6` (terasa). Uzly: P1 vstup, P2 kuchyň, P3 obývací pokoj, P4 spací nika, P5 koupelna, P6 terasa.
- **Video:** [ke stažení v Releases](https://github.com/thebehunek/byt-a-lidicka/releases/download/v1/byt-a-prochazka.mp4) — 1 732 snímků, 1920 × 1080, 25 fps, 69 s.

Zdrojová scéna a výkresy nejsou součástí tohohle repozitáře.
